MACHINE LEARNING MINI PROJECT - SIMPLE EXPLANATION

Title:
Iris Flower Classification Using Machine Learning Algorithms

Aim:
To classify an iris flower into Setosa, Versicolor or Virginica using machine learning.

Dataset:
We use only one dataset, called the Iris dataset. It contains flower measurements:
- Sepal length
- Sepal width
- Petal length
- Petal width

The output is the flower species.

Algorithms:
1. KNN: It checks the nearest data points and predicts the most common class among them.
2. Decision Tree: It makes decisions using feature-based questions, like branches of a tree.
3. Logistic Regression: It estimates the probability that a flower belongs to each class and selects the most likely class.

Steps:
1. Import libraries.
2. Load the Iris CSV dataset.
3. Separate input features and output label.
4. Split data into 80% training and 20% testing.
5. Train KNN, Decision Tree and Logistic Regression.
6. Predict flower species using test data.
7. Calculate and compare accuracy.

Conclusion:
All three algorithms are applied to the same dataset. Their test accuracies are compared, and the model with the highest accuracy is identified.

VIVA QUESTIONS:
Q1. What is a dataset?
A. A dataset is a collection of related data used for analysis or machine learning.

Q2. What is classification?
A. Classification is a machine learning task that predicts a category or class.

Q3. What is KNN?
A. KNN predicts a class by looking at the nearest data points.

Q4. What is a Decision Tree?
A. It is an algorithm that makes predictions using a tree-like structure of decisions.

Q5. What is Logistic Regression?
A. It is an algorithm used to predict class probabilities.

Q6. What is accuracy?
A. Accuracy is the percentage of test predictions that are correct.

Q7. Why do we split the dataset?
A. We train the model on one part and test it on unseen data to check performance.
