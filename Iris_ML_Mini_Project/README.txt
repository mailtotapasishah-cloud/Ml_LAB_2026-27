IRIS FLOWER CLASSIFICATION - MINI PROJECT

FILES
1. Iris_ML_Mini_Project.ipynb - complete notebook with code and explanations
2. iris_dataset.csv - the single dataset used by all three algorithms
3. Project_Explanation.txt - simple explanation for lab/viva

HOW TO RUN IN GOOGLE COLAB
1. Open https://colab.research.google.com/
2. Upload Iris_ML_Mini_Project.ipynb.
3. In the left Files panel, upload iris_dataset.csv.
4. Run the notebook cells from top to bottom.

HOW TO RUN IN JUPYTER
1. Keep the notebook and CSV in the same folder.
2. Install required packages if needed:
   pip install pandas scikit-learn matplotlib
3. Open the notebook and run all cells.

IMPORTANT
The notebook reads the supplied CSV file. It does not download or import another dataset.
The exact accuracy can vary if you change the train/test split or model settings.
