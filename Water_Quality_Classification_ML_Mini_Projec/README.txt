WATER QUALITY CLASSIFICATION - MINI PROJECT

Files:
1. Water_Quality_Classification.ipynb - Notebook
2. water_quality_dataset.csv - Single dataset
3. Project_Explanation_and_Viva.txt - Explanation and viva questions
4. README.txt - Run instructions

Google Colab:
1. Upload the notebook to Google Colab.
2. Upload water_quality_dataset.csv using the Files panel on the left.
3. Run all cells from top to bottom.

Libraries: pandas, matplotlib, scikit-learn.
Dataset: Synthetic educational sample data; not real water-test data.
Do not use this project to make real drinking-water safety decisions.
